# Rafay — Creative Developer Portfolio

A polished, responsive portfolio landing page built with vanilla HTML, CSS and JavaScript.

## Features
- Responsive mobile-first navigation
- Animated reveal effects
- Interactive cursor glow
- Modern editorial-style visual system
- Project showcase and contact section
- No frameworks or build step required

## Run locally
Open `index.html` in a browser.

## Customize
Edit the content in `index.html` and the design tokens at the top of `style.css`.
